Hexy

A cross-platform desktop app for drawing hex maps and running them at the table. Fog of war hides what players haven’t found; Display mode mirrors the map to a second screen in real time, revealing hexes as they explore. Built solo and shipped to itch.io.

Tech Stack

  • Tauri + Rust for the cross-platform desktop shell
  • SvelteKit 5 + TypeScript for the editor UI
  • PixiJS for the hex-grid renderer
  • Vitest and Playwright for unit and end-to-end coverage
  • GitHub Actions for build and release
